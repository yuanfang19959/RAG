# 把问答挂件嵌进博客（PageIo）

本文只提供可复制的代码，**P3 阶段不改动 PageIo 仓库**。

## 方案

RAG 服务把前端产物挂在自己的 `/ui` 下，博客用 iframe 引这个地址：

```
博客页面 (www.yuanfang19959.icu)
  └─ 右下角按钮 → iframe src="https://rag.你的域名/ui/#/widget"
                      └─ iframe 内部调 /chat/stream（与 iframe 同源，不跨域）
```

为什么用 iframe 而不是把聊天组件直接装进 Next.js：

- 博客是 antd 5，Ant Design X 要求 antd 6，同仓会打架
- 聊天应用可以独立部署、独立更新，不用每次都重新发博客
- 样式完全隔离，博客的全局 CSS 不会影响挂件
- 代价是父子页面要靠 `postMessage` 通信，主题色需要手动同步

## 博客侧组件

放在 PageIo 的 `components/RagWidget/index.tsx`：

```tsx
'use client';

import { useEffect, useRef, useState } from 'react';

const WIDGET_SRC = process.env.NEXT_PUBLIC_RAG_WIDGET_URL!;

export default function RagWidget() {
  const [open, setOpen] = useState(false);
  // 首次点击才赋值 src，避免拖慢博客首屏
  const loaded = useRef(false);
  if (open) loaded.current = true;

  useEffect(() => {
    const onMessage = (event: MessageEvent) => {
      // 只认自己那个域发来的消息
      if (new URL(WIDGET_SRC).origin !== event.origin) return;
      if (event.data?.type === 'rag-widget:close') setOpen(false);
    };
    window.addEventListener('message', onMessage);
    return () => window.removeEventListener('message', onMessage);
  }, []);

  return (
    <>
      {loaded.current && (
        <iframe
          title="RAG 问答"
          src={WIDGET_SRC}
          style={{
            position: 'fixed',
            right: 24,
            bottom: 92,
            width: 380,
            height: 560,
            border: 'none',
            borderRadius: 12,
            boxShadow: '0 12px 32px rgba(0,0,0,.18)',
            display: open ? 'block' : 'none',
            background: '#fff',
            zIndex: 1000,
          }}
        />
      )}
      <button
        onClick={() => setOpen((v) => !v)}
        style={{
          position: 'fixed',
          right: 24,
          bottom: 24,
          width: 56,
          height: 56,
          borderRadius: '50%',
          border: 'none',
          background: '#1677ff',
          color: '#fff',
          cursor: 'pointer',
          zIndex: 1001,
        }}
      >
        问
      </button>
    </>
  );
}
```

在 `app/layout.tsx` 里挂一次即可，`.env.local` 加 `NEXT_PUBLIC_RAG_WIDGET_URL=https://rag.你的域名/ui/#/widget`。

移动端建议改成全屏：宽高用 `100vw` / `100dvh`，`right/bottom` 归零。

## 服务端要注意的

**1. 允许被博客 iframe 引用。** 默认没问题，但如果加了安全头，必须放行：

```nginx
# 不要用 X-Frame-Options: DENY / SAMEORIGIN
add_header Content-Security-Policy "frame-ancestors https://www.yuanfang19959.icu";
```

**2. 关掉反代缓冲，否则流式会被攒成一坨再吐出来：**

```nginx
location / {
    proxy_pass http://127.0.0.1:8000;
    proxy_http_version 1.1;
    proxy_buffering off;
    proxy_read_timeout 300s;
}
```

后端已经带了 `X-Accel-Buffering: no`，nginx 会尊重它，但显式配上更稳。

**3. 先构建前端再启动后端。** 静态目录是在应用启动时挂载的：

```bash
cd frontend && pnpm install && pnpm build   # 产物到 ../static/ui
uv run rag                                   # 再起后端
```

**4. 公开到互联网前必须做的（P4）：** 现在 `/chat/stream` 谁都能调，直接烧的是你的 DeepSeek 额度。上线前至少要有 IP 限流，最好复用博客的 JWT 做鉴权。
