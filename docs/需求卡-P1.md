# 需求卡：P1 文档入库（上传 → 切块 → 向量化）

## 1. 一句话需求

开发者上传一份文本文档后，系统能把它切成小块、算出向量并存进 `rag_db`，为 P2 的检索问答准备数据。

## 2. 本期做 / 不做

### 做

- `documents` / `chunks` 两张表（`chunks.embedding` 用 pgvector）
- 建表脚本（含 `vector` 扩展与 HNSW 索引）
- 上传接口：接收 `.txt` / `.md`，落盘到 `uploads/`，登记一条 `documents`
- 入库接口：读文件 → 切块 → 调 embedding → 写 `chunks`，并更新文档状态
- 列表 / 详情接口，能看到每篇文档切了多少块
- 重复入库幂等：同一文档再次 ingest 会先清掉旧块

### 不做

- 检索、`/chat`、流式输出（P2 / P3）
- PDF / Word 解析（先只支持纯文本）
- 鉴权、多用户隔离
- 后台任务队列（ingest 先同步执行）
- 博客同步（P4）

## 3. 成功标准（可验收）

- [x] `uv run rag-init-db` 能建出 `documents` / `chunks` 表和向量索引
- [x] `POST /documents` 上传 `.md` 文件返回文档 id，状态为 `pending`
- [x] `POST /documents/{id}/ingest` 返回切块数量，状态变 `ready`
- [x] 数据库里 `chunks.embedding` 有 1024 维向量
- [x] 同一文档重复 ingest 不会产生重复块
- [x] 上传 `.pdf` 之类不支持的后缀返回 400（空文件同样 400，缺失文档 404）

## 4. 数据设计

库：`rag_db`（PostgreSQL 16 + pgvector 0.8.6，已就绪）

### documents

| 字段 | 类型 | 说明 |
|------|------|------|
| `id` | UUID | 主键 |
| `title` | text | 文件名或自定义标题 |
| `source_type` | text | `upload` / 以后 `blog` |
| `source_uri` | text | 落盘路径 |
| `status` | text | `pending` / `ready` / `failed` |
| `error` | text | 失败原因 |
| `chunk_count` | int | 切块数量（冗余字段，方便列表展示） |
| `created_at` / `updated_at` | timestamptz | |

### chunks

| 字段 | 类型 | 说明 |
|------|------|------|
| `id` | UUID | 主键 |
| `document_id` | UUID | 外键 → `documents`，级联删除 |
| `chunk_index` | int | 在原文里的顺序 |
| `content` | text | 块正文 |
| `embedding` | vector(1024) | bge-m3 的维度 |
| `created_at` | timestamptz | |

索引：`hnsw (embedding vector_cosine_ops)`，用于 P2 的余弦相似度检索。

## 5. API 契约

| 方法 | 路径 | 说明 |
|------|------|------|
| POST | `/documents` | multipart 上传文件，登记文档 |
| POST | `/documents/{id}/ingest` | 切块 + 向量化 |
| GET | `/documents` | 列表 |
| GET | `/documents/{id}` | 详情 |

### 错误码

| HTTP | 场景 |
|------|------|
| 400 | 后缀不支持 / 文件为空 |
| 404 | 文档不存在 |
| 503 | 未配置 embedding key，或库不可用 |

## 6. 主流程

1. `POST /documents` → 文件存 `uploads/{uuid}{后缀}`，插入 `documents`（`pending`）
2. `POST /documents/{id}/ingest`
   - 读取文件文本
   - `RecursiveCharacterTextSplitter` 切块（默认 500 字 / 重叠 80）
   - 调硅基流动 `Pro/BAAI/bge-m3` 批量算向量
   - 事务内：删旧块 → 插新块 → 更新 `status=ready`、`chunk_count`
3. 出错则 `status=failed`，`error` 记原因

## 7. 失败与边界

| 场景 | 预期行为 |
|------|----------|
| embedding key 没配 | 503，文档保持 `pending` |
| embedding 接口报错 | 文档置 `failed` 并记录原因，返回 502 |
| 文件内容为空 | 400 |
| 切块数为 0 | 400 |
| 重复 ingest | 先删旧块，结果一致（幂等） |

## 8. 非功能

- ingest 同步执行，大文件会阻塞请求 → 后续可改后台任务
- 向量维度与表结构强绑定：换 embedding 模型要改列定义并重建索引
- 密钥只在 `.env`，不入库

## 9. 依赖与风险

| 项 | 状态 |
|----|------|
| pgvector | 已装（0.8.6，为 PG16 源码编译） |
| embedding 服务 | 复用已有硅基流动 key（`Pro/BAAI/bge-m3`，1024 维） |
| LLM | P2 才需要，复用 DeepSeek key |
